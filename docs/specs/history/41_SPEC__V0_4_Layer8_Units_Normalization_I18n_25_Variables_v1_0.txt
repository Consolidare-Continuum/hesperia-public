0. LAYER-8 CONTRACT (INVARIANT)
----------------------------------------------------------------------

  Layer-8 does not introduce new math. It defines unit taxonomy, scaling policy, conversion functions, and canonical "report units" (SI_*) for every metric the stack emits. For every metric: raw (native), unitType, scaledPct if ratio-like, scaledU1000 if ratio-like, policy. This makes the whole stack internationally readable and comparable. Deterministic formatting for stable logs.

1. PREREQUISITES
----------------------------------------------------------------------

  L1 .. L7 = outputs from Layers 1–7 (34_SPEC … 40_SPEC). All SI_* values are derived from L1–L7 using the conversion functions and policies below.

2. LAYER-8 UNITS, NORMALIZATION, INTERNATIONALIZATION (25)
----------------------------------------------------------------------
A. Unit system enums and policies (1–5)
----------------------------------------------------------------------

 1. UNIT_TYPE_ENUM
    enum UnitType { COUNT, RATIO, PERCENT, U1000, RADIANS, SECONDS, BYTES, HASH, BOOLEAN, CODE }
    Standard unit taxonomy for every emitted metric.

 2. SCALE_POLICY_ENUM
    enum ScalePolicy { RAW, CLAMP_0_1, CLAMP_0_100, CLAMP_0_1000, ZSCORE, LOG10 }
    How values are scaled for reporting.

 3. EPSILON_POLICY
    double EPS = 1e-12;
    Global numeric floor to avoid divide-by-zero and acos domain failures. Used in all conversions.

 4. CLAMP_POLICY
    double clamp(double v, double lo, double hi) { return max(lo, min(hi, v)); }
    Single clamp rule used everywhere. int version: clamp(i, lo, hi) for integer bounds.

 5. ROUNDING_POLICY
    int DECIMALS_RATIO = 6;
    int DECIMALS_PCT = 2;
    int DECIMALS_U1000 = 0;
    Deterministic formatting for stable logs.

----------------------------------------------------------------------
B. Canonical conversion functions (6–13)
----------------------------------------------------------------------

 6. RATIO_TO_PCT
    double ratioToPct(double r) { return clamp(r, 0.0, 1.0) * 100.0; }
    Dimensionless ratio → percent (0..100).

 7. RATIO_TO_U1000
    int ratioToU1000(double r) { return (int) round(clamp(r, 0.0, 1.0) * 1000.0); }
    Ratio → 0..1000 reference units.

 8. PCT_TO_U1000
    int pctToU1000(double pct) { return (int) round(clamp(pct, 0.0, 100.0) * 10.0); }
    0..100% → 0..1000.

 9. U1000_TO_PCT
    double u1000ToPct(int u) { return clamp(u, 0, 1000) / 10.0; }
    0..1000 → percent.

10. RAD_TO_DEG_OPTIONAL
    double radToDeg(double rad) { return rad * (180.0 / π); }
    Radians remain canonical; degrees optional for human display.

11. SIGNED_DELTA_TO_U1000
    int signedDeltaToU1000(double delta, double maxAbs) {
      double d = clamp(delta / max(EPS, maxAbs), -1.0, 1.0);
      return (int) round(500.0 + 500.0 * d);
    }
    500 = no change; <500 = negative delta; >500 = positive delta.

12. SCORE_TO_U1000_CLAMP
    int scoreToU1000(double score, double lo, double hi) {
      double r = (score - lo) / max(EPS, (hi - lo));
      return ratioToU1000(clamp(r, 0.0, 1.0));
    }
    Maps any bounded score into U1000.

13. LOG_BOUNDED_TO_U1000
    int logBoundedToU1000(double x, double xMax) {
      double r = log10(1.0 + clamp(x, 0.0, xMax)) / log10(1.0 + xMax);
      return ratioToU1000(r);
    }
    For heavy-tailed counts (tokens, nodes).

3. PRACTICAL CONTRACT (WHAT YOU LOG EVERYWHERE)
----------------------------------------------------------------------

  For every metric you emit:
    - raw (native)
    - unitType (from UnitType enum)
    - scaledPct if ratio-like
    - scaledU1000 if ratio-like
    - policy (CLAMP_0_1 / RAW / etc.)
    - goodDirection (UP / DOWN / NEUTRAL) — optional but useful

  Example record shape (Java POJO idea):
    name: "COVERAGE_RATIO"
    raw: 0.82341
    unit: RATIO
    pct: 82.34
    u1000: 823
    policy: CLAMP_0_1

  This makes the whole stack internationally readable and comparable.

enum UnitType { COUNT, RATIO, PERCENT, U1000, RADIANS, SECONDS, BYTES, HASH, BOOLEAN, CODE }
enum ScalePolicy { RAW, CLAMP_0_1, CLAMP_0_100, CLAMP_0_1000, ZSCORE, LOG10 }

final double EPS = 1e-12;
static double clamp(double v, double lo, double hi) { return Math.max(lo, Math.min(hi, v)); }
final int DECIMALS_RATIO = 6, DECIMALS_PCT = 2, DECIMALS_U1000 = 0;

static double ratioToPct(double r) { return clamp(r, 0.0, 1.0) * 100.0; }
static int ratioToU1000(double r) { return (int) Math.round(clamp(r, 0.0, 1.0) * 1000.0); }
static int pctToU1000(double pct) { return (int) Math.round(clamp(pct, 0.0, 100.0) * 10.0); }
static double u1000ToPct(int u) { return clamp((double) u, 0, 1000) / 10.0; }
static double radToDeg(double rad) { return rad * (180.0 / Math.PI); }
static int signedDeltaToU1000(double delta, double maxAbs) {
  double d = clamp(delta / Math.max(EPS, maxAbs), -1.0, 1.0);
  return (int) Math.round(500.0 + 500.0 * d);
}
static int scoreToU1000(double score, double lo, double hi) {
  double r = (score - lo) / Math.max(EPS, (hi - lo));
  return ratioToU1000(clamp(r, 0.0, 1.0));
}
static int logBoundedToU1000(double x, double xMax) {
  double r = Math.log10(1.0 + clamp(x, 0.0, xMax)) / Math.log10(1.0 + xMax);
  return ratioToU1000(r);
}
