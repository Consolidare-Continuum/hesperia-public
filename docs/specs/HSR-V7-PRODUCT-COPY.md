# HSR-V7 — Product copy (Gate E-02)

**Version:** 0.6.5+router  
**Audience:** Operator, partner, public one-liners

## Say

- Hesperia is **deterministic semantic middleware** — sealed engine trace, governed routing, optional LLM narration under policy.
- The **router/governor** compiles input into a `RouterInputEnvelope`, calls LLM only through a bounded `RouterPromptEnvelope`, and audits output into `RouterDecision`.
- **Provenance is inspectable** (`router_fingerprint`, `corpus_snapshot_id`, `output_hash`) — not vendor chain-of-thought.

## Do not say

- "Hesperia understands you" / "AI that understands clinical text"
- "Hesperia's answer" (use **generated text** or **model narrative**)
- "Inspectable reasoning" / "see how the model thinks"

## Short EN

> Hesperia routes clinical text through a sealed semantic engine, attaches corpus provenance, and governs optional LLM output — middleware, not a black-box oracle.

## Short RO (terms in English)

> Hesperia este middleware semantic determinist: engine trace sigilat, router/governor, LLM opțional sub policy — nu un oracol care „înțelege”.
