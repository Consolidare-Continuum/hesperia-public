## What this era actually is

This is the era where Hesperia stops being a guard-checked API stub and becomes a real, full L1–L9
pipeline with frozen inputs. Three structural threads run in parallel:

1. **Lexicon freeze.** `19d28a40`, `93b5292f`, `dd0d107f` establish Dict A (surface) / Dict B
   (concept) as frozen, checksummed, versioned artifacts with an explicit fallback tier (B0) and a
   hard-gated next tier (B1) — see [`corners/lexicon_resolver.md`](../corners/lexicon_resolver.md).
2. **Sphere stack.** `dcb4695a` and `802efcf9` introduce the full layer architecture this repo
   still uses — topology, dynamism, logic, metrics, USF, pipeline, guards, plus testing and
   interface layers — followed quickly by `63febce1`'s Layer-10 interpretation and USF
   consolidation, and a second Prolog sub-layer ("L9b"). This is essentially the architecture
   described in `specs/canon/fpf_bridge_v7.md`'s input contract seven eras later, already present
   in skeletal form. See [`corners/sphere_pipeline.md`](../corners/sphere_pipeline.md).
3. **Sealing and provenance.** `c6bcf14c` through `a1c82762` build the first sealed-runtime gate,
   complete with an architecture fingerprint tied to a document→commit→tag evidence chain and an
   OpenTimestamps proof — the direct ancestor of the 0.6.x dev/prod sealing discipline. See
   [`corners/release_governance.md`](../corners/release_governance.md).

`6d5cb52d ORDER: repo-wide naming (4 words + version), artifacts in subfolders, specs at root` is a
small but telling commit: the first explicit repo-hygiene rule enforcing that *specs* (the canon)
live in a predictable, separate location from artifacts — the precursor of today's `specs/canon/`
vs. everything-else split. Once text actually has to flow through nine layers, "which span produced
which concept" stops being optional bookkeeping and becomes the only way to debug the pipeline at
all — the moment `core/attribution`, `core/resolver`, and `core/lexical` solidify as distinct
concerns. See [`corners/layer_contracts_attribution.md`](../corners/layer_contracts_attribution.md).

## Why this ordering was the minimal right move

Freezing the lexicon *before* building the full sphere stack (rather than after) meant every layer
built on top of Dict A/B from day one assumed a stable concept vocabulary, instead of being
retrofitted later when the lexicon eventually froze — avoiding a much larger later migration. The
sealing discipline's "quarantine legacy, then remove it only after the sealed gate passes" two-step
pattern (`5eef4a61` then `a1c82762`) never deletes material before proving the gate works *without*
that material present — the same "verify, then commit" discipline the guard triad applies at the
data level, applied here at the repo-hygiene level.
